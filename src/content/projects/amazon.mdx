## Overview

On Amazon, shoppers decide in seconds, usually on a phone, usually by swiping through images. I designed those images for eleven brands: the main listing images, the A+ content further down the page, and brand storefronts.

Every set had one job: answer the shopper's questions before they ask, and make the product feel worth more than the one next to it.

## What I learned

<Points
  items={[
    { title: 'Design for the swipe', body: 'Each image must work alone, because shoppers skip around.' },
    { title: 'Facts beat adjectives', body: 'Numbers, tests and comparisons convinced more than slogans.' },
    { title: 'Local matters', body: 'French and Dutch versions needed new layouts, not just translation.' },
    { title: 'One look per brand', body: 'A consistent style made storefronts feel like real brands.' },
