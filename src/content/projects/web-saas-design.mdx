## Overview

Five websites for freelance clients, each in a different industry. For every one I worked directly with the client, planned the pages, and designed the full site in Figma, ready to build. Hover over any page to scroll through the whole design.

<Points
  items={[
    { title: 'Understand the business', body: 'Start with what the client sells, who buys it and what the site must make people do.' },
    { title: 'Plan the pages', body: 'Map the pages and the order of sections before any visual design.' },
    { title: 'Design the system', body: 'Pick type, colour and components once, then use them on every page.' },
    { title: 'Desktop and mobile', body: 'Design the key pages for both, so the build matches the design on any screen.' },
  ]}
/>

## What I learned

<Points
  items={[
    { title: 'Every industry has its own trust signals', body: 'Prices for a shop, security for payments, numbers for finance, real photos for construction.' },
    { title: 'A small system goes far', body: 'A few shared components kept each site consistent and quick to design.' },
    { title: 'Clients decide on the homepage', body: 'Getting the first screen right made every later page easier to agree on.' },
    { title: 'Design for the build', body: 'Clear styles and mobile layouts meant fewer questions from developers.' },
  ]}
/>
