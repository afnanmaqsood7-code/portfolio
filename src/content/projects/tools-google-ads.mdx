## Overview

A US brand selling construction and tile tools wanted to start on Google Ads with a small test budget and grow only if the numbers worked.

I built the account from scratch and ran it myself: strategy, setup, feed work, copy, testing and reporting.

## What I did

<Points
  items={[
    { title: '1. Shopping first', body: 'Shopping campaigns gathered data fastest, showing which products and searches actually convert.' },
    { title: '2. Product tiers', body: 'I split products into top performers and testing groups, so winners got budget and new products still got a chance.' },
    { title: '3. Better feed', body: 'I rewrote product titles and descriptions around the words buyers search for.' },
    { title: '4. Search from real data', body: 'Non-brand Search was built from the best converting Shopping terms, then branded Search captured existing demand as spend grew.' },
  ]}
/>
